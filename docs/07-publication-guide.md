# Publishing the research website

The repository can be browsed in GitHub without downloads. For an optional styled website, enable GitHub Pages in **Settings → Pages → Build and deployment → GitHub Actions**. Then run the `Publish case-study site` workflow.

The page URL is expected to be `https://drkasber1-art.github.io/binance-hot-wallet-incident-2026/` after successful deployment. Do not advertise it as live before verification.

Review the evidence and sources prior to publishing updates. GitHub Actions tests operate offline; they do not verify the current state of Ethereum.
