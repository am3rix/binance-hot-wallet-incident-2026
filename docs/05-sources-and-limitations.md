## Limitations

This project does not claim access to Binance internal telemetry, malware artifacts, employee communications, signing hardware or forensic images. Public transaction tracing can establish movement and execution but not the full path of compromise. A wallet's explorer label is not cryptographic evidence of its legal owner. Third-party dollar estimates depend on asset prices and precise data snapshots.

The repository deliberately contains no exploitation code, signer secrets or live transaction broadcasting. The diagrams are interpretive illustrations, not recovered attack infrastructure.

## Correction policy

Corrections should identify the specific assertion, an independently accessible source and the proposed change. Earlier snapshots should be retained in Git history.
