02 / PROTOCOL

What EIP-7702 changes.

A signed authorization can cause an externally owned account to delegate execution to another address. The transaction does not reveal how the signature was obtained.

01

Authorization

Type 0x04 transaction carrying chain, delegate, nonce and signature information.

02

Account code

A designator can point execution to delegated code, subject to protocol validity checks.

03

Execution

Calls execute delegate logic in the wallet's context. Transaction receipts show effects, not operator intent.
